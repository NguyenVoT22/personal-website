Salvare Oceanum

Devpost ・ Website

Agent Code

GitHub Repository ・ Website

Agent Code is a website designed to close the gender gap and racial gap in computer science. Our website will educate
students with the computing skills they’ll need to pursue pursue this field while providing them with opportunities
to expand their knowledge. Current ly have lessons in HTML/CSS, Python, and JavaScript. Made with HTML/CSS and
JavaScript; I lead the group won second place, website made in HTML/CSS and JavaScript. I learned how to make a
game ("Game" page) with HTML/CSS and JavaScript, and worked on the "Project Ideas" and "More Resources."
